# การตรวจต้นแบบ

## ตรวจ UX/UI รุ่น 2

- ตรวจ Dashboard ใหม่ในเบราว์เซอร์: กราฟระดับถังอิงยอดข้อมูลชุดเดิม มีเปอร์เซ็นต์/ลิตร แยกสีถังต่ำ และแสดงรอข้อมูลเมื่อไม่มีบันทึก
- ตรวจเมนูหลักตามบทบาทและทางเข้าบันทึกประจำวัน
- ทดลองพนักงานกรอกสองส่วน น้ำมัน → เงินรับและหลักฐาน → ตรวจทาน สำเร็จ
- ตรวจภาพมือถือ 390×844 และความกว้างหน้า ไม่มีการล้นแนวนอน
- รันการตรวจตรรกะเดิมอีกครั้ง: สูตรน้ำมัน สิทธิ์ รายงานสิ้นเดือน ข้อมูลขาด ประวัติถัง และการลงรายจ่ายไม่ซ้ำผ่าน (ชุดนี้ตรวจข้อมูลเดิม ส่วนหน้ารุ่น 2 ตรวจผ่านเบราว์เซอร์)

ตรวจ 27 กันยายน 2569 ในเบราว์เซอร์ของ Codex และตรวจตรรกะภายในด้วย Node (`node verify.cjs`)

## สถานการณ์สำหรับเจ้าของธุรกิจทดลองต่อ

1. ผู้จัดการส่งกลับพร้อมเหตุผล แล้วพนักงานแก้และส่งใหม่
2. เจ้าของเปิดแก้ย้อนหลังและดูประวัติฉบับก่อนแก้
3. เลือกยอดขายเฉพาะชนิดน้ำมัน ตรวจว่าไม่ต้องเดารายถัง
4. เพิ่มรับเข้าและเบิกใช้ที่อนุมัติ ตรวจยอดรวมรายวัน
5. ขอเบิกใหม่ → อนุมัติ → จ่าย → หลักฐาน → เคลียร์ กรณีใช้เกินวงเงินหรือคืนไม่ครบ
6. เพิ่ม/แก้/ปิดใช้งานในแต่ละหมวด Admin และตรวจถังต่างสาขา
7. ทดลองนำเข้าและส่งออก Excel ซึ่งเป็นหน้าจอจำลองเท่านั้น

## ขอบเขตการทดสอบ

นี่เป็นการตรวจต้นแบบ ไม่ใช่การรับรองระบบการเงินพร้อมใช้งานจริง ยังไม่มีการทดสอบระบบล็อกอิน ฐานข้อมูล ความปลอดภัย การอัปโหลด การอ่าน/เขียน Excel การทำงานพร้อมกัน หรือการกู้คืนข้อมูล เพราะยังไม่มี backend เหล่านี้ ไม่ได้ทดสอบกับโทรศัพท์จริงหรือ screen reader
